# Retail Sales Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Retail Sales Dashboard built using Microsoft Power BI**. The dashboard provides a clear overview of sales performance, profit, customers, products, regions, and other important business KPIs.

The main objective of this project is to transform raw retail sales data into meaningful insights that can help businesses understand their performance and make data-driven decisions.

## 🎯 Key Features

* Executive overview of overall business performance
* KPI cards for **Total Sales, Profit, Profit Margin, Orders, Customers, and Target Achievement**
* Monthly Sales and Profit trend analysis
* Sales and profit analysis by category and region
* Top-performing products and customers
* Target vs Actual Sales comparison
* Customer and product drill-through pages
* Interactive slicers for Year, Month, Category, Region, Segment, and Payment Method
* Dynamic visualizations and filters for detailed analysis

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated columns
* **Microsoft Excel** – Data source and preprocessing

## 📈 Key Analysis

The dashboard helps analyze:

* Overall sales and profitability
* Monthly sales trends
* Product and category performance
* Regional sales performance
* Customer purchasing behavior
* Sales team performance
* Target achievement
* High-sales and low-margin products
